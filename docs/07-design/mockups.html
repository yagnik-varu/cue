Cue · design reference

Cue UI Mockups

Pixel reference for the Android app, web app and Chrome extension. Every colour, size and radius here comes from the tokens in docs/07-design/ui-ux-design.md §3. Build from this; don't invent new styles.

A · Android app

Mobile: capture first, three tabs, nothing extra

One big + button on every tab. Swipe right turns an Inbox item into a todo, swipe left archives it, and long-press shows every action.

B · Web app

Web: three panes, keyboard first, calm sidebar

A dim sidebar, a 36 px list and a detail panel on the right. Every action has a single-key shortcut, and the hint bar teaches them.

C · Chrome extension

Extension: one field, page attached, zero setup

The popup captures in one keystroke, with the current page attached. The side panel shows notes for this page and follows the active tab.
